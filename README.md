# OpenGameGallery
Gallery of board games available free to play online.
Currently, only Chess is available, as the project just started.
In the future, more games are planned, such as Draughts and Reversi.

Online play is planned to be available, soon, however it is currentlty unavailable.

This game is still in very early development. Many features may be broken or removed. Development should stabilize after the online system is finished.
